## Checks completed before fixes

- Both repositories had clean Git working trees at audit start.
- Generated sitemap: all 78 URLs returned HTTP 200 locally.
- All concrete non-dynamic page files were crawled. Normal routes returned 200; `/404` and `/500` behaved as framework error routes.
- Confirmed the nine broken navigation targets above with direct HTTP requests.
- Search API returned results for accented Portuguese input (`café`), including non-ASCII city/address data.

- Static review confirmed UUID-shape guards in current city/place API paths; further dynamic-data testing remains required.
